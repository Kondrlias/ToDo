ТЗ React To-Do List

### 1. Цель проекта

- Сделать небольшое приложение «список дел», чтобы студенты прокачали навыки работы с React, хуками и стейтом.

### 2. Основные функции

1. **Добавление задачи**
    [+] Поле ввода + кнопка «Добавить».
    [+] Пустые или пробельные строки — не добавлять, выводить предупреждение.
2. **Отмечать выполнение**
    [+] Каждая задача имеет чекбокс.
    [+] При отметке задача перечёркивается.
3. **Удаление задачи**
    [+] У кнопки «×» справа от задачи — удаляет этот пункт.
4. **Редактирование задачи**
    [+] По клику на кнопку редактировать она переходит в режим редактирования.
    [+] Вводится новое значение, подтверждение Enter или кнопкой Save.
    [+] Пустые строки не сохранять.
    [+-] При отмене (Escape или click outside) значение остаётся прежним.
6. **Сохранение в localStorage**
    [+] После перезагрузки страницы список и статусы сохраняются.
7. **Чистка завершённых**
    [+] Кнопка «Очистить выполненные» — удаляет все отмеченные.
