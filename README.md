# ТЗ: React To‑Do List — Подключение к API ✅

### 📍 Что изменилось?

Теперь твоя задача — **перевести всё приложение на работу с реальным сервером**, используя API.

---

### 1. Цель доработки

- Научиться работать с реальным API: загружать, создавать, обновлять и удалять задачи.
- Прокачать понимание асинхронных запросов и управления состоянием при работе с внешними данными.
- Это уже похоже на реальные проекты, которые ты будешь делать на работе.

---

### 2. Что конкретно нужно сделать

Заменить `localStorage` на взаимодействие с удалённым сервером:

[**https://todo-redev.herokuapp.com/api-docs**](https://todo-redev.herokuapp.com/api-docs)

1. Реализовать страницу Регистрации. 
2. Реализовать страницу авторизации пользователя с формой входа: логин, пароль. 
После входа, необходимо сохранить токен. Полученный токен использовать для авторизации - проверка наличия токена в localStorage, если токена нет, значит пользователь не авторизован (видит только страницу авторизации).

### 🔄 Загрузка задач

[+] При запуске приложения загружай список всех задач:
    - `GET /todos`
- Сохраняй их в `state`.

### ➕ Добавление задач

[+] При добавлении — делай `POST`:
    - `POST /todos`

### ☑️ Отметка выполнения

[-] Меняй статус задачи, отправляя `PATCH`:
    - `PUT /todos/:id/isCompleted`

### 📝 Изменять задачу

[+] Меняй название задачи, отправляя `PATCH`:
    - `PUT /todos/:id`

### 🗑 Удаление задачи

[+] `DELETE /todos/:id`

### 🧼 Очистка завершённых

- Удаляй все задачи, где `status === "done"`:
    - несколько запросов `DELETE`

### 🔍 Фильтрация

- Работает по-прежнему через `state`, но данные — с сервера.
- Фильтруй уже загруженные задачи в интерфейсе.

---

### 3. Что обязательно:

- ❗️**Никакого localStorage** — только API.
- Добавь **загрузку (loading)** и **обработку ошибок (error)**.
- UI должен оставаться отзывчивым: показывай спиннеры, дизейбли кнопки на время запроса и т.д.
